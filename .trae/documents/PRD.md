## 1. 产品概述

全天候大气化学-气溶胶-云相互作用模拟与空气质量智能预警平台，面向环境监测中心、空气质量预测中心及应急指挥部，提供从排放源清单上传、三维化学传输模型构建、气相化学-气溶胶-云微物理全链路模拟，到多级预警推送、排放削减方案自动调整、综合报告生成的一站式智能决策支持系统。

- 解决大气复合污染模拟流程碎片化、预警响应迟缓、减排策略缺乏数据驱动等核心问题
- 目标用户为环境科学家、空气质量预测人员及应急指挥决策者，产品价值在于实现模拟-预警-决策的自动化闭环

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 环境科学家 | 管理员分配 | 上传数据、创建模拟任务、验证模型合理性、查看报告 |
| 空气质量预测人员 | 管理员分配 | 确认预警级别、复核预警推送、审核排放削减方案 |
| 应急指挥部人员 | 管理员分配 | 接收预警推送、生成公众健康防护建议、查看综合看板 |
| 首席科学家 | 管理员分配 | 处理异常区域暂停通知、审批关键决策、查看全局统计 |
| 系统管理员 | 系统内置 | 用户管理、系统配置、数据维护 |

### 2.2 功能模块

1. **综合看板页面**：每日统计概览、性能趋势图、源贡献饼图、关键指标卡片
2. **模拟任务管理页面**：任务创建与文件上传、九态状态流转可视化、任务列表与筛选
3. **实时监控页面**：PM2.5/O3浓度实时曲线、气溶胶光学厚度热力图、区域预警状态
4. **预警中心页面**：多级预警列表、复核流程、排放削减方案调整、调整日志
5. **报告中心页面**：PDF报告生成与下载、污染物浓度等值面图、辐射效应云图、SOA贡献分解图
6. **智能推荐页面**：历史模拟结果分析、最优减排策略推荐、排放情景对比
7. **审批中心页面**：两级审批流程、首席科学家通知、审批历史

## 3. 核心流程

### 3.1 模拟任务全流程

用户上传排放源清单、气象场及气溶胶光学特性文件后，系统自动构建三维化学传输模型并初始化气相化学机制与气溶胶模块。模拟任务按九态状态机自动流转，计算过程中实时监控地面PM2.5、O3浓度和气溶胶光学厚度。当某区域污染物超过国家二级标准或光学厚度异常时自动触发多级预警推送至环境监测中心复核，复核通过则自动调整排放削减方案并重新模拟，记录调整日志。模拟完成后自动生成综合报告PDF。

```mermaid
flowchart TD
    "A[上传数据文件]" --> "B[待校验]"
    "B" --> "C[数据融合]"
    "C" --> "D[网格生成]"
    "D" --> "E[气相化学迭代]"
    "E" --> "F[气溶胶模拟]"
    "F" --> "G[云微物理]"
    "G" --> "H[空气质量评估]"
    "H" --> "I{是否超标?}"
    "I" -->|"是"| "J[触发预警]"
    "J" --> "K[环境监测中心复核]"
    "K" -->|"通过"| "L[调整排放削减方案]"
    "L" --> "D"
    "K" -->|"不通过"| "M[异常回退]"
    "I" -->|"否"| "N[完成]"
    "H" --> "M"
    "N" --> "O[两级审批]"
    "O" --> "P[科学家验证模型合理性]"
    "P" --> "Q[预测中心确认预警级别]"
    "Q" --> "R[推送至应急指挥部]"
    "R" --> "S[生成健康防护建议]"
```

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：深海蓝（#0A1628）为底色，科技青（#00D4AA）为主强调色，琥珀橙（#FF8C00）为预警色，珊瑚红（#FF4757）为危险色
- **按钮风格**：圆角微凸3D效果，主按钮使用青色渐变，危险操作使用红色
- **字体**：数据展示使用 JetBrains Mono 等宽字体，标题使用 Noto Sans SC，正文使用系统字体
- **布局风格**：左侧固定导航栏 + 顶部信息条 + 主内容区，卡片式模块布局
- **图标风格**：线性图标（Lucide），配合数据可视化图表
- **氛围效果**：深色主题模拟航天控制中心风格，数据面板带微弱辉光边框，预警元素带脉冲动画

### 4.3 响应式设计

- 桌面优先设计，主要适配1920×1080及1440×900分辨率
- 1280px以下自适应为紧凑布局（侧边栏折叠为图标模式）
- 移动端适配基础浏览功能，操作功能引导至桌面端

### 4.4 3D场景指引

- 气溶胶光学厚度热力图采用2.5D透视效果，模拟大气层视角
- 云微物理模块使用Three.js渲染简易3D云层粒子效果
- 等值面图支持3D视角切换，可旋转查看空间分布
